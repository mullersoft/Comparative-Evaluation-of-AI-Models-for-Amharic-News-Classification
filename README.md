
# Amharic News Classification

This repository contains the Jupyter Notebook used in the study **"Comparative Evaluation of Traditional Machine Learning, Deep Learning, and Transformer Models for Six-Category Amharic News Classification."**

The notebook compares traditional machine learning, deep learning, and transformer models for classifying Amharic news articles into six categories: National, International, Politics, Business, Sports, and Entertainment.

### Models
- SVM with TF-IDF
- CNN
- BiLSTM with Attention
- AfriBERTa-large with Cross-Entropy Loss
- AfriBERTa-large with Focal Loss

### Dataset
The study uses the [Amharic News Text Classification Dataset](https://huggingface.co/datasets/israel/Amharic-News-Text-classification-Dataset). After preprocessing, 50,706 articles were retained and split into training (70%), validation (10%), and testing (20%) sets.

### Usage
Open the Jupyter Notebook in Google Colab or a local Jupyter environment and run the cells sequentially. Install any required dependencies and follow the dataset access instructions in the notebook.
